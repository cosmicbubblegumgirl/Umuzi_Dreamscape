Umuzi Dreamscape Desktop Browser App

This package opens the live Umuzi Dreamscape GitHub Pages app in a clean
desktop-style browser window.

Quick start:
1. Double-click "Umuzi Dreamscape.cmd".
2. If Windows asks which app to use, choose Microsoft Edge or Google Chrome.
3. Optional: right-click "Install Desktop Shortcut.ps1" and choose Run with
   PowerShell to create a desktop shortcut.

The launcher uses Microsoft Edge first, then Google Chrome. If neither browser
is available, it opens the live app in the default browser.
